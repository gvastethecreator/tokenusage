# Triage labels

## Categories

- `bug`: existing accepted behavior fails.
- `enhancement`: adds or improves product behavior.

## Status

- `needs-triage`: scope or impact still needs review.
- `needs-info`: required evidence, permission, or input is missing.
- `ready-for-agent`: an AFK task has a bounded deliverable and proof.
- `ready-for-human`: a HITL task needs a user choice or action.
- `wontfix`: deliberately rejected with a reason.

Dependencies live in `Blocked by`; labels identify task ownership and readiness contract.
