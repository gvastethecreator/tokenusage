# README banner

Imagegen created the textless mascot layer in `raw/readme-hero.png`. The final SVG embeds that original image and adds selectable title text. It is an illustration, not a product screenshot.

Direction requested by Cristian: simple, silly, deliberately uneven drawing. A bean-shaped character loses count of colored token slips. Warm off-white, black, mint, lavender, and orange. No photorealism or generic technology imagery.

The README screenshots are captured separately from the actual application using sample data.
