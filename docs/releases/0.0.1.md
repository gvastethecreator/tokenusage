# TokenUsage 0.0.1

TokenUsage 0.0.1 is the first public pre-release for Windows.

## Included

- Local token and cost reports for supported AI coding tools
- Codex quota limits and reset-cycle history
- Global and provider dashboards
- Compact tray view and tray summary
- Stable CLI output for usage, reports, limits, providers, and diagnostics
- Signed MSIX and portable ZIP distributions for Windows x64

## Portable ZIP

Extract the complete ZIP. Then run `TokenUsage.App.exe`.

Run `tokenusage.cmd` from PowerShell to use the portable CLI.

The portable app and CLI store their data in the local `Data` folder. Keep this folder when you update the app.

## Known limits

- Provider coverage depends on the local data that each installed tool exposes.
- TokenUsage displays unavailable values as unavailable. It does not create estimated quota values.
- The release supports Windows x64. ARM64 remains a build target, but this release does not include an ARM64 asset.
