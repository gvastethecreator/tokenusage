## English (United States)

### Product name

TokenUsage

### Short description

See quota, tokens, cost, activity, and reset cycles for your AI coding tools in one local-first Windows app.

### Full description

TokenUsage brings usage information from supported AI developer tools into one clear Windows experience.

Open the tray panel for a fast status check. Open the detailed report to compare providers, time ranges, tokens, costs, quota observations, and reset cycles. Use the packaged command-line utility for scripts and diagnostics.

TokenUsage is designed around honest data states. Provider-reported cost is kept separate from locally estimated cost. Partial, stale, unavailable, unsupported, and unpriced values remain visible instead of being silently converted into misleading totals.

The application is local-first. It reads bounded, documented sources on your computer and does not require a TokenUsage account. Network-enabled provider connections remain opt-in and are used only when a user explicitly configures a documented integration.

Provider coverage depends on the installed product, account type, product version, and data source available on the device. A provider listed in the catalog is not automatically a live integration.

### Features

- Fast tray view for current usage and quota status
- Detailed provider, token, cost, activity, and reset-cycle reports
- Clear distinction between reported, estimated, partial, stale, unavailable, and unpriced data
- Local-first storage with no TokenUsage account required
- English and Spanish interface
- Packaged `tokenusage` command-line utility with human-readable and versioned JSON output
- Export-friendly report surfaces
- Diagnostics that explain missing or unsupported provider data

## Español

### Nombre del producto

TokenUsage

### Descripción breve

Consulta cuotas, tokens, costos, actividad y ciclos de reinicio de tus herramientas de programación con IA en una app local para Windows.

### Descripción completa

TokenUsage reúne información de uso de herramientas de desarrollo con IA compatibles en una experiencia clara para Windows.

Abre el panel de la bandeja para una consulta rápida. Usa el reporte detallado para comparar proveedores, períodos, tokens, costos, observaciones de cuota y ciclos de reinicio. La utilidad de línea de comandos incluida permite automatizar consultas y ejecutar diagnósticos.

TokenUsage está diseñado para mostrar el estado real de los datos. Los costos informados por un proveedor se mantienen separados de los costos estimados localmente. Los valores parciales, desactualizados, no disponibles, no compatibles o sin precio permanecen identificados en vez de convertirse en totales engañosos.

La aplicación prioriza el funcionamiento local. Lee fuentes acotadas y documentadas en tu computadora y no requiere una cuenta de TokenUsage. Las conexiones de red con proveedores son opt-in y solo se utilizan cuando el usuario configura explícitamente una integración documentada.

La cobertura depende de la herramienta instalada, tipo de cuenta, versión del producto y fuente disponible en el dispositivo. Que un proveedor aparezca en el catálogo no significa que tenga una integración activa.
